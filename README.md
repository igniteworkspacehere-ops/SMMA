# DIGISPECT SMMA Starter

Next.js 14 App Router starter for a premium SMMA marketing website.

## Stack

- Next.js 14 + TypeScript + TailwindCSS
- Framer Motion animations
- Swiper slider for portfolio
- Supabase client for dynamic CMS data

## Getting Started

```bash
npm install
npm run dev
```

Create `.env.local` using `.env.example`.

## Routes

- `/` - landing page
- `/services`
- `/portfolio`
- `/contact`
- `/admin/login`
- `/admin/dashboard`
